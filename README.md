# BotForge

**No Code, No Hassle — Just Powerful Chatbots at Your Fingertips**

BotForge is a comprehensive no-code platform that empowers users to create, customize, and deploy AI-powered chatbots without any programming knowledge. Built on modern web technologies, it offers sophisticated chatbot creation capabilities with seamless integration options for websites and applications.

## Overview

BotForge revolutionizes chatbot development by providing an intuitive, visual interface for creating intelligent conversational agents. The platform combines the power of OpenAI's language models with extensive customization options, API integrations, and a flexible credit-based system to deliver enterprise-grade chatbot solutions accessible to everyone.

## Core Features

### 🤖 **Intelligent Chatbot Creation**
- **AI-Powered Conversations**: Leverages OpenAI's GPT models for natural, context-aware responses
- **Interactive Bot Builder**: Chat-like interface guides users through the bot creation process
- **Custom Personalities**: Define bot purpose, tone, and behavioral characteristics
- **Multi-Modal Support**: Handle text and image inputs for richer interactions
- **Conversation Memory**: Maintains context throughout chat sessions

### 🎨 **Visual Customization**
- **Brand Alignment**: Customize colors, logos, and visual elements to match your brand
- **Chat Interface Styling**: 
  - Custom bubble colors for bot and user messages
  - Configurable text colors and chat backgrounds
  - Typing indicator customization
  - Header styling and branding
- **Widget Positioning**: Choose optimal placement on your website
- **Responsive Design**: Works seamlessly across desktop and mobile devices

### 🔗 **API Integration System**
- **Dynamic API Connections**: Integrate existing APIs to provide real-time, data-driven responses
- **Intelligent Triggers**: Configure when specific APIs should be called based on user intent
- **Parameter Mapping**: Flexible system for passing user inputs to API endpoints
- **Response Processing**: Automatically format API responses into conversational messages
- **Header Configuration**: Support for authentication and custom headers

### 🌐 **Multi-Language Support**
- **Global Reach**: Support for multiple languages to serve international audiences
- **Automatic Language Detection**: Adapts to user's preferred language
- **Localized Responses**: Culturally appropriate and contextually relevant conversations

### 💰 **Flexible Pricing & Credit System**
- **Credit-Based Usage**: Pay only for what you use with transparent pricing
- **Multiple Payment Plans**:
  - **Starter Plan**: $3 for 100 credits, ideal for testing and small projects
  - **Smart Plan**: Automatic recharging with customizable amounts
  - **Custom Payment**: One-time payments with full control over spending
- **Automatic Billing**: Seamless credit renewal to prevent service interruptions
- **Usage Analytics**: Track credit consumption and bot performance

### 🚀 **Easy Integration**
- **Simple Embed Code**: One-line JavaScript integration for any website
- **Plug-and-Play Setup**: No technical knowledge required for deployment
- **Cross-Platform Compatibility**: Works with any website or web application
- **CDN Delivery**: Fast loading times with global content delivery

## Architecture & Technology Stack

### Frontend
- **Next.js 14**: React-based framework for server-side rendering and optimal performance
- **React 18**: Modern component-based UI with hooks and context management
- **Ant Design**: Professional UI components for consistent user experience
- **Material-UI**: Additional design components for enhanced functionality
- **CSS Modules**: Scoped styling for component-based architecture

### Backend
- **Next.js API Routes**: Serverless backend functions for scalable API endpoints
- **MongoDB**: NoSQL database for flexible data storage and retrieval
- **Mongoose**: Object modeling for MongoDB with schema validation
- **NextAuth.js**: Secure authentication with OAuth providers

### AI & External Services
- **OpenAI API**: GPT-4 and GPT-4-mini models for conversational AI
- **Stripe**: Payment processing and subscription management
- **Google OAuth**: Secure user authentication and account management

### Development Tools
- **Axios**: HTTP client for API communications
- **React Toastify**: User-friendly notifications and alerts
- **FontAwesome**: Professional iconography
- **Prism.js**: Syntax highlighting for code examples
